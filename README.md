# 🚀 Gemini AI Clone (React)

A modern **Gemini AI clone UI** built using **React.js** with a clean design and responsive layout.
This project simulates an AI chat interface with sidebar navigation and dynamic responses.

---

## ✨ Features

- 💬 Chat interface (AI-style response UI)
- 📂 Sidebar with toggle (expand / collapse)
- 🧠 Context API for global state management
- ⚡ Real-time input handling
- 🎨 Clean and modern UI design
- 📱 Responsive layout (mobile + desktop)
- 🔄 Loading animation (skeleton effect)

---

## 🛠️ Tech Stack

- **Frontend:** React.js
- **State Management:** Context API
- **Styling:** CSS3
- **Icons & Assets:** Custom assets

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/gemini-clone.git
```

2. Navigate to project folder:

```bash
cd gemini-clone
```

3. Install dependencies:

```bash
npm install
```

4. Start development server:

```bash
npm run dev
```

## 🧠 How It Works

- User enters a prompt
- `onSent()` function is triggered
- Data is processed via Context API
- Result is displayed in chat UI
